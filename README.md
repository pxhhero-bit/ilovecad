# IloveCAD

一个面向 **2D 工程图纸** 的轻量级桌面 CAD 看图 + 轻度修改软件。基于 GNU
LibreDWG 做 DWG 读写内核，Qt for Python (PySide6) 做原生桌面界面。

> **纯净版承诺**：本项目**没有任何广告、没有会员 / VIP 等级、没有订阅、没有
> 账号体系、没有云盘依赖、没有遥测上报、没有功能付费墙**。源码里出现的每一个
> 功能，对每一个用户都无条件可用。请不要以任何形式向本项目的衍生发行版加入
> 上述内容——这与项目的许可和使用约定直接冲突。

> **本项目只处理 2D 图纸。3D 图纸支持被明确、永久地跳过。** 不带任何 3D 实体
> 渲染、3D 视图、三维导航、点云、网格或实体建模能力；遇到 3D 实体（3DSOLID、
> 3DFACE、REGION、SURFACE、MESH、ACIS 数据等）时，软件会在导入报告中明确列出
> 「已跳过」，不会假装显示、不会静默丢弃、也不会把它们写回文件。UI 中不存在
> 「视觉样式 / 三维视图 / 模型渲染」一类入口。这是设计决定，不是待办事项。

## 硬性架构约定

| 约定 | 落地方式 |
|---|---|
| 读写内核 | GNU LibreDWG（GPL-3.0-or-later），通过 `dwgread` / `dwgwrite` 调用，源码位于 `src/ilovecad/kernel/` |
| 写入锁定 R2004 | 唯一常量 `TARGET_VERSION = "AC1018"`；`dwgwrite --as r2004`；写出后校验文件头 == `AC1018` 并回读，失败即拒绝落盘，**无 R2000 静默回退** |
| 高版本读入 | R2007 / R2010 / R2013 / R2018 走**源头降版本兜底**：先在临时副本上转成 R2004 再进入文档模型，原文件永不改写，并生成导入报告 |
| PDF 输出 | **独立渲染路径**：从统一 DisplayList 直接送专用 PDF 绘制设备，不经过 DWG 写入、不截图、不调用 `dwg2ps` / `dwg2SVG`，与 DWG 版本闸门完全解耦 |
| 读写分层 | 打开 / 导入**默认只读**：源文件字节（SHA-256 登记）、导入 DXF 快照、2D 显示模型三层分离；写入管线默认关闭，须 `EDIT` 显式确认降级风险后启用 |
| 开源许可 | 全项目 `GPL-3.0-or-later`，每个源文件带 SPDX 头；二进制发行附对应源码，见 `THIRD_PARTY.md` |

## 功能

**看图**：打开 DWG（R13–R2004 直读，R2007–R2018 降版本兜底）与 ASCII DXF；
图层列表、灯泡开关、冻结、颜色 / 线型 / 线宽；平移、滚轮缩放、窗口缩放、
适应全图（`Z` / `FIT`，按实体密度定位主体图幅，自动剔除远处独立图框 / 离群对象）、
`FITALL` / `ZEXTENTS` 查看含离群对象的完整范围、网格、正交；
坐标与比例尺状态栏。

**实体显示**：LINE、LWPOLYLINE / POLYLINE（含凸度圆弧）、CIRCLE、ARC、
ELLIPSE、POINT、TEXT / MTEXT、SOLID、INSERT 块参照展开；SPLINE 按节点矢量 /
阶数求值 NURBS 曲线后以折线显示，HATCH 显示闭合边界与近似斜线图案（不做实心
填充）；MTEXT 清除字体 / 高度 / 颜色等格式控制码并保留多行换行；DIMENSION
只显示可解析文字；其余在导入报告中计数说明。

**对象捕捉**：按类型独立开关——**边界点 / 端点 / 顶点**（直线端点、多段线每个
真实顶点、圆弧起终点）、**线段 / 圆弧中点**、**中心 / 圆心**（圆、圆弧、椭圆
中心，以及闭合多段线的面积中心）、象限点、交点、垂足、最近点、文字插入点、
POINT 节点。候选点取自真实几何数据，**不使用显示时的细分折线**（否则一个圆会
凭空产生上百个假端点并淹掉真正的圆心）；按「端点 / 交点 / 中心 / 中点 / 象限点 /
最近点」的加权优先级取最优点，光标处按类型绘制方块 / 三角 / 圆+十字 / 菱形 /
X / 直角等标记及中文标签。`F3` 或 `SNAP` 是全局开关，`OSNAP` / `SNAPSET`
或「视图 → 对象捕捉设置…」打开设置页，可逐类勾选、把捕捉半径调为 3–40 px、
一键恢复默认；配置只写本机 INI。

**测量**：两点距离及水平垂直分量、方位角、多段累计长度、闭合区域面积、
半径 / 直径 / 弧长；**夹角测量**（三点法「顶点 → 第一边点 → 第二边点」，或
直接点取两条直线 / 多段线；输出较小夹角、补角、弧度、两边方位角与交点，并在
画布和 PDF 上绘制角弧标注）；单位换算与精度设置。结果列表支持单击高亮、
双击定位到标注、右键删除单条 / 复制数值 / 导出 CSV。命令别名 `ANG` / `DAN`
（三点）与 `AL` / `ANGLELINE`（两线）。`HELP` / `F1` 显示完整命令与快捷键表。

**只读 / 编辑分层**：打开图纸默认只读（详见下文专章）。只读期间看图、图层显隐、
对象捕捉、测量、矢量 PDF、批量转换都可用；`EDIT` 或「进入编辑」确认风险后，
才降级为 2D 可编辑模型并启用下面的编辑能力；「原样副本」按字节复制源文件，
不经过任何重建。

**轻量编辑**：点选 / 窗选 / 多选；绘制直线、多段线、矩形、圆、圆弧、文字；
删除、移动、复制、旋转、**镜像（`MI` / `MIRROR`）、缩放（`SC` / `SCALE`）**；
图层管理器（新建 / 重命名 / 删除并把实体迁到 0 层 / 设为当前 / 锁定 / 批量显隐）；
属性面板双击批量改图层、颜色、线型、线宽、坐标、半径、字高、旋转角、文字内容；
锁定图层仍可见可捕捉但不可编辑；撤销重做命令栈（大图纸自动收紧历史上限）；
保存 / 另存为（**始终 AC1018**），保存前明确列出将丢失或近似的对象。

**输出**：矢量 PDF（A4 / A3 / A2、比例、当前视图 / 全图 / 完整范围、彩色 / 黑白、
线宽映射、可含测量标注）、AC1018 DXF、**批量转换**（多文件 / 整个目录 →
R2004 DWG 或 AC1018 DXF，带进度与逐文件日志；输出文件名自动加后缀，
原文件永不改写、已有输出永不覆盖，高版本走源头降版本兜底，跳过对象写入日志）。

│ 图层面板  │                                  │ 属性面板      │

**界面主题与设置**：**默认深色（黑底）**，在「视图 → 界面主题与对象捕捉设置…」

`.ui` 不会被样式覆盖。PDF 输出始终为白底纸张，不受界面主题影响。

## 目录结构

```

src/ilovecad/
  kernel/     LibreDWG 适配层：版本闸门、源头降版本、R2004 写入锁定、导入报告
  model/      文档模型：实体、图层、单位、几何计算、只读会话分层（session.py）
  render/     DisplayList + Qt 屏幕绘制 + 独立 PDF 绘制路径
  tools/      类型化捕捉、测量、编辑命令与撤销重做栈
  ui/         Qt Designer .ui 源文件、画布控件、窗口控制器、批量转换
  theme.py    深色 / 浅色主题配色与本机设置持久化
  preferences.py  对象捕捉配置的本机 INI 读写
  fonts.py    统一的中文 fallback 字体策略
  app.py      应用逻辑入口（创建 QApplication 与主窗口，由 main.py 调用）
scripts/
  fetch_libredwg.py      下载并校验锁定版本的 LibreDWG（含对应源码）
  compile_ui.py          把 .ui 编译为 Python
  run.py                 兼容启动器（与 main.py 等价）
  make_source_bundle.py  生成合规的对应源码包
tests/                   单元测试与往返回归
```

## 快速开始（Windows / Linux / macOS）

```bash
python -m pip install -r requirements.txt
python scripts/fetch_libredwg.py          # 下载锁定的 LibreDWG 二进制 + 源码
python scripts/compile_ui.py              # 编译 .ui -> Python（启动时也会自动重编）
python main.py                            # 启动
python main.py tests/台秤方案.dwg          # 启动并直接打开图纸
python scripts/run.py                     # 等价的兼容启动器
```

入口文件就是仓库根目录的 `main.py`；它只负责把 `src/` 加入模块搜索路径，
然后调用 `src/ilovecad/app.py` 的 `main()`。命令行传入的第一个 `.dwg` /
`.dxf` 路径会在启动时自动打开，也可以把图纸直接拖到 `main.py` 上运行。

Linux / macOS 上没有官方预编译包时，`fetch_libredwg.py` 会打印源码构建命令；
按 `THIRD_PARTY.md` 用 `./configure && make` 构建即可，程序会自动探测
`dwgread` / `dwgwrite`。

## 只读 / 编辑分层（重要）

真实图纸测试暴露了「读写一体」的问题：一打开就把源文件重建为有损的 2D 模型，
此后任何误操作都可能触发 DXF 重序列化。现在管线分成三层：

| 层 | 内容 | 是否可写 |
|---|---|---|
| 源文件层 | 原 `.dwg` / `.dxf` 字节，打开时登记 SHA-256 | **永不改写** |
| 只读快照层 | 导入器输出的完整 DXF（`DocumentSession.import_dxf`），保留 2D 模型之外的原始信息 | 只存内存，不参与写出 |
| 2D 显示模型 | `DwgDocument`，用于渲染、吸附、测量、矢量 PDF | 只读会话中禁止写入 |

* **打开后默认只读**：标题栏 / 状态栏显示 `[只读]`，画布有独立硬闸门——绘制、
  变换、删除、撤销重做、属性与图层写操作全部拒绝，即使绕过 UI 直接调用
  `CadCanvas.set_mode()` / `_add()` 也会被拦。看图、图层显隐、对象捕捉、测量、
  矢量 PDF 导出、批量转换均不受影响。
* **只读下的「另存为」= 无损原样副本**：`kernel.copy_source()` 按字节复制源文件，
  强制同格式后缀、禁止覆盖源、复制前后 SHA-256 校验、原子替换。XDATA、代理对象、
  高版本特性全部保留，完全不经 DXF 重建。也可用「原样副本」按钮 / 菜单 /
  `SAVECOPY`。只读下「保存」与「导出重建 DXF」被拒绝，并给出「原样副本」或
  「进入编辑」两个出口。
* **编辑是一次显式降级**：点「编辑 → 进入编辑模式」、编辑页「进入编辑」或输入
  `EDIT` / `ED` / `EDITMODE`，先弹出风险对话框，列出源版本与哈希、导入快照大小、
  跳过的 3D / 不支持对象数量、SPLINE / HATCH 等近似数量、XDATA / 复杂块丢失、
  R2004 写锁与不可回退说明。确认后 `DocumentSession.enter_edit()` 才把会话降级为
  2D 可编辑模型，随后走原有编辑 / 保存管线；取消则一切不变。
* 降级是**单向**的，且只改内存模型；想恢复未修改状态请重新打开源文件。空白未命名
  图纸没有源文件要保护，直接可编辑。
* **任何模式下都不覆盖源文件**：即使已降级进入编辑，`Ctrl+S` 也会说明原因并
  转到「另存为」；「另存为」/ DXF 导出同样禁止选中源文件路径。编辑模式下保存前
  还会重新核对源文件哈希，若被外部程序改动则拒绝写入；R2004 文件头 + 回读实体数
  校验、高版本 / DXF 只能另存为等既有闸门全部保留。

## 源文件保护与写入校验

真实图纸（R2018、5976 实体 / 57 图层）驱动的一轮红队复查后，写入链路增加了
以下硬约束：

* **任何源文件都不允许被 `Ctrl+S` 覆盖**（只读会话直接拒绝；降级进入编辑后弹
  说明并转到「另存为」）。读入时在临时副本上降版本的高版本图纸、`.dxf` 源文件
  尤其不会被 DWG 二进制写回原路径。原文件字节始终不变（自检用 SHA-256 验证）。
* **另存为不允许选中当前源文件**；覆盖其它已存在文件时同样需要确认。
* **回读校验是真校验**：写出前由编码器统计实际可写实体数，写出后回读数量必须
  与之严格相等，否则拒绝落盘并保留原文件。LibreDWG 早期版本曾因 DXF 骨架缺失
  静默丢弃全部实体，只报「可解析 N 个」是不够的。
* **不静默丢数据**：未知实体类型直接拒绝保存；SPLINE / HATCH / MTEXT /
  DIMENSION 的 2D 近似写出、无有效顶点的空对象、退化填充边界（按 POINT 保留
  位置）都会写进保存报告，并在确认对话框里列出数量。
* **源单位不改写**：显示 / 测量使用本机选择的单位与精度，但写出时 `$INSUNITS`
  保留源图纸原值；`$INSUNITS=0`（无单位）会在导入报告里明确警告。
* **文本编码容错**：LibreDWG 偶尔在中文字符串中输出被截断的 UTF-8 字节，解码器
  按行容错，只替换损坏字符，不再让整份图纸的图层名与文字退化为 latin-1 乱码。
* **HATCH 边界按 DXF 的 93 顶点数分段**，并排除头部 elevation point，避免把
  `(0,0)` 当成边界顶点画出贯穿全图的假斜线，也避免把多条闭合边界合成一个多边形。
* **显示与写回分层**：屏幕上 SPLINE 求值真实 NURBS 曲线、HATCH 画边界轮廓 +
  近似斜线图案，均不再误画成控制多边形或大块实心白色填充；MTEXT 的格式控制码
  （`{\fSimHei|b0|i0|c134|p49;…}`、`\A1;`、`|b0|i0|c1|p0;\o\l` 等）在解析时
  剥离，`\P` 换行按多行绘制，不再拼成一条横贯画布的长字符串；纯格式碎片不渲染。
  异常巨大的字高只按主体几何比例做**显示限高**，源文件字高与写出字高保持不变。
* **SPLINE 解析节点矢量 / 阶数 / 权重**，用 de Boor 算法求值；节点缺失时回退到
  钳位均匀节点，绝不把控制多边形当成曲线本身。

## 版本策略

* 文件头 `AC1015` / `AC1018`（R2000 / R2004）→ 直接解码。
* `AC1021` / `AC1024` / `AC1027` / `AC1032`（R2007 / 2010 / 2013 / 2018）→
  **源头降版本**：`dwgread -O DXF` → `dwgwrite --as r2004` 生成临时低版本
  DWG → 再解码，全过程在 LibreDWG 内完成，不捆绑任何专有转换器。
* 用户可在设置里填写**自备**的外部转换器路径作为最后一级可选钩子；该组件
  既不随发行版分发，也不是必需依赖。
* 保存永远输出 `AC1018`；写出后在临时文件上校验文件头与回读结果，通过后才
  原子替换目标文件。校验失败保留原文件并写日志。

## 已知限制

* **不支持 3D 图纸**（见开头说明），也不支持参数化约束、动态块、代理对象、
  外部参照、天正自定义实体的完整语义。
* LibreDWG 的 R2004 编码器仍是 beta；本项目固定含 0.14.1 安全修复的 nightly，
  并对每次写入做回读校验。
* SHX 字体不做完整字库，中文 / 特殊符号以系统字体近似替代，缺失时在导入
  报告中列出。
* 对象捕捉基于读入后的 2D 实体几何；代理对象、外部参照与未展开的复杂块内部
  子实体不参与捕捉（它们本来也不会被显示或写回）。
* 保存时会用**结构完整的 AC1018 DXF 骨架**重建模型（含 `BLOCK_RECORD` 表、
  唯一句柄与 `330` owner 引用——LibreDWG 的 DXF importer 缺少这些会静默丢弃
  全部实体），因此原图的 XDATA / 代理对象 / 复杂块定义不会原样回写；保存前
  会明确列出将丢失的对象并需要确认，**不会静默丢数据**。这种情况只发生在
  「确认降级进入编辑」之后；只读会话不会重建任何文件，需要完全相同的副本请用
  「原样副本」。
* **写回仍是 2D 近似**：SPLINE 以求值后的折线写出（不是原生样条，长度不能当作
  原曲线长度）；**HATCH 只保留边界多段线**，屏幕 / PDF 的斜线图案不写回；
  MTEXT 按单行 TEXT 写出，多行与格式语义丢失。真实图纸里这几类对象的数量会
  写进导入报告与保存确认框。
* `$INSUNITS=0` 的无单位图纸：测量数值按本机显示单位解释，出图比例请自行核对
  图纸实际单位；软件不会猜测或改写源单位标记。
* 「适应全图」按 64×64 实体密度网格定位主体图幅（连通的非空格子），把远处独立
  图框 / 离群对象排除在视图之外，并在状态栏提示忽略数量；`FITALL` 可查看完整
  范围，PDF「完整范围」始终包含全部对象，不会静默漏掉任何对象。PDF「全图」
  与屏幕一致，使用主体图幅范围。
* 大图纸（>5000 实体）的撤销历史上限自动收紧到 20 步，以控制内存占用。
